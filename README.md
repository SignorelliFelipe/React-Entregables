# BookWave 📚

BookWave es un proyecto realizado como trabajo final del curso de React en Coderhouse.

Se trata de una tienda online de libros de fantasía donde el usuario puede recorrer un catálogo, filtrar por categorías, ver el detalle de cada libro, agregar productos al carrito y finalizar una compra.

## Funcionalidades

- Ver el catálogo completo de libros.
- Filtrar productos por categorías.
- Ver el detalle de cada libro.
- Agregar productos al carrito.
- Modificar las cantidades desde el carrito.
- Vaciar el carrito.
- Finalizar una compra.
- Generar una orden de compra en Firebase Firestore.

## Tecnologías utilizadas

- React
- React Router DOM
- Context API
- Firebase Firestore
- CSS

## Base de datos

El proyecto utiliza Firebase Firestore para almacenar:

- Productos del catálogo.
- Órdenes de compra generadas por los usuarios.
